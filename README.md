# TigerOS

A custom Windows-based operating system experience.

## Identity
Name: TigerOS
Version: 1.0
Architecture: x64
Theme: Dark Black + Electric Blue
Logo: Cyber Tiger Head

## Operating System
Base: Microsoft Windows 11
Linux: Ubuntu through WSL2
Windows applications: Native
Linux commands: Bash

## Main Features
- Custom TigerOS branding
- Custom desktop experience
- TigerOS startup branding
- Windows application support
- Integrated Ubuntu terminal
- PowerShell automation
- Custom installation configuration

## Development
Primary development device: Android
Development environment: Termux
Budget: Free tools
